# Publicação da landing page

A página deste projeto deve ser publicada em:

`https://phytomaster.com.br/landingpage/`

O site institucional existente deve continuar respondendo em `https://phytomaster.com.br/`.

## Configuração necessária na hospedagem

- Mapear `/landingpage/` para a pasta pública deste projeto.
- Manter os caminhos relativos para `assets/`, `styles.css` e os arquivos JavaScript.
- Garantir resposta HTTP 200 para a URL com barra final.
- Integrar `/landingpage/` ao sitemap e ao `robots.txt` já existentes no domínio.

Os metadados `canonical` e `og:url` já estão configurados em `index.html` para essa URL.
